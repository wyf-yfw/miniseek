# MiniSeek-M0.1 MoE Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implement MiniSeek-M0.1 every-layer DeepSeekMoE (`1 shared + 32 routed`, top-2, expert intermediate 512) on d=512/L=8, wire `train_pretrain.py --arch miniseek-moe`, and let the Web train UI choose Dense vs MoE.

**Architecture:** Keep `DenseLM` unchanged for D0.1. Add real `MoELM` in `model/moe.py` that reuses attention/RMSNorm/RoPE helpers from `model/dense.py`. MoE FFN = shared expert always-on + top-2 routed experts; training loss = CE + λ·load-balance aux. Web UI adds an architecture selector that passes `--arch` into the training command and loads either Dense or MoE checkpoints for inference.

**Tech Stack:** PyTorch, existing FastAPI `web_ui.py` + `web/index.html`, pytest smoke tests, MiniMind tokenizer vocab=6400.

**Spec:** `docs/superpowers/specs/2026-10-25-miniseek-m0.1-moe-design.md`

## Global Constraints

- Backbone: `d_model=512`, `n_layers=8`, `n_heads=8`, `head_dim=64`, `vocab_size=6400`, `max_seq_len` train default 512
- MoE: `n_shared_experts=1`, `n_routed_experts=32`, `num_experts_per_tok=2`, `moe_intermediate_size=512`
- Target total params ≈ **150M** (±5%); print `numel` on init
- Attention stays **full causal** (no SWA in this plan)
- Compare data: `pretrain_t2t_mini.jsonl`; full pretrain is a later optional track, not required to finish this plan
- No tool/agent SFT in this plan
- Prefer TDD: failing test → implement → pass → commit per task
- User prefers in-repo edits (not Cursor CloudAgent) unless they ask

### Task 2: Expert MLP + MoE layer + aux loss

**Files:**
- Modify: `model/moe.py` (replace placeholder)
- Modify: `model/dense.py` only if needed so `RMSNorm`, `CausalSelfAttention`, `precompute_rope_cis`, `count_parameters` are importable
- Test: `tests/test_moe.py`

**Interfaces:**
- Produces:
  - `class ExpertMLP(nn.Module)`: `forward(x) -> Tensor` shape preserved `(..., d)`
  - `class MoELayer(nn.Module)`: `forward(x) -> Tuple[Tensor, Tensor]` = `(y, aux_loss)` where `aux_loss` is scalar tensor
  - `def load_balance_loss(router_probs: Tensor, topk_idx: Tensor, n_experts: int) -> Tensor`
- Consumes: `ModelConfig` fields above; import `RMSNorm` / attention later in Task 3

Aux formula (Switch-style, locked here):

```text
f_i = fraction of tokens routed to expert i (from top-k indices, count/ (T*k) normalized over experts as mean one-hot)
P_i = mean router probability for expert i over tokens
aux = n_experts * sum_i (f_i * P_i)
```

```python
class ExpertMLP(nn.Module):
    def __init__(self, d_model: int, intermediate: int, dropout: float = 0.0):
        super().__init__()
        self.fc1 = nn.Linear(d_model, intermediate, bias=False)
        self.fc2 = nn.Linear(intermediate, d_model, bias=False)
        self.dropout = nn.Dropout(dropout)

    def forward(self, x):
        return self.dropout(self.fc2(F.gelu(self.fc1(x))))


class MoELayer(nn.Module):
    """1 shared + N routed, top-k; returns (y, aux_loss)."""
    def __init__(self, cfg: ModelConfig):
        ...
        self.shared = ExpertMLP(...)
        self.experts = nn.ModuleList([ExpertMLP(...) for _ in range(cfg.n_routed_experts)])
        self.router = nn.Linear(cfg.d_model, cfg.n_routed_experts, bias=False)
        self.top_k = cfg.num_experts_per_tok

    def forward(self, x):  # (B,T,D)
        b, t, d = x.shape
        flat = x.reshape(b * t, d)
        shared_out = self.shared(flat)
        logits = self.router(flat)
        probs = F.softmax(logits, dim=-1)
        topk_prob, topk_idx = torch.topk(probs, self.top_k, dim=-1)
        topk_prob = topk_prob / topk_prob.sum(dim=-1, keepdim=True).clamp_min(1e-9)
        routed = torch.zeros_like(flat)
        # dropless gather: for each of top_k slots, add expert(flat)*weight
        for slot in range(self.top_k):
            idx = topk_idx[:, slot]
            w = topk_prob[:, slot].unsqueeze(-1)
            # dispatch per unique expert id (loop experts or vectorized)
            ...
        y = (shared_out + routed).view(b, t, d)
        aux = load_balance_loss(probs, topk_idx, self.n_routed)
        return y, aux
```

Keep expert loop correct but simple (B*T ~ thousands at this scale).

```python
    def forward(self, x, rope_cis):
```

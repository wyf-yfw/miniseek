# MiniSeek SFT v5 混数设计

日期：2026-10-28  
状态：已批准（对话确认）  
范围：设计定稿；**本阶段不下载数据、不改训练/WebUI 默认、不删 v1**。实现与落盘另开 plan。

## 目标

1. 产出两份 Conversations JSONL 盘量包：约 **5G**、约 **10G**（磁盘体积，非参数量）。
2. 混数落盘并验收后（另一步，用户确认后执行）：
   - 清理旧 **v1** SFT 数据（本地与后续 HF 对齐）；
   - WebUI / 训练默认指向 **10G** 包；**5G** 仅留作小跑对照；
   - 上传 HF `wyf-yfw/MiniSeek-SFT`（**仅 train 主文件** + 卡片文档；Hub **不上**独立 valid；本地仍用 `--valid-ratio`）。
3. **不打扰**正在跑的 `moe-sft-3`（及其他进行中的训练进程）。

## 已锁定配比（按样本条数）

### 能力桶（无安全 / 无工具专用桶）

| 桶 | 占比 |
|----|------|
| 对话 / 通用指令 | 43% |
| 知识 QA | 22% |
| 推理 / 数学 | 15% |
| 创作 / 写作 | 12% |
| 代码 | 8% |

合计 100%。**不设**独立安全拒答桶、**不设**独立工具调用桶。

### 轮次

- 单轮 **75%** / 多轮 **25%**  
- 对话桶内多轮比例可高于全局，以拉齐总控 25%。

### 语言

- 中文 **80%** / 英文 **20%**

5G 与 10G **共用同一套配比**，仅总盘量不同。

## 产出物

| 路径 | 说明 |
|------|------|
| `data/SFT/sft_miniseek_v5_5g.jsonl` | ≈5G 对照包 |

- 落盘优先 **wyf** 本机 `/home/wyf/miniseek/data/SFT/`（正式训练源）；大 `.jsonl` 仍 gitignore，不进公仓。

## 数据源路线 A（已定）

主料 + 弱项补丁：

| 能力桶 | 目标占比 | 主来源 | 补料 |
|--------|----------|--------|------|
| 对话 43% | 体感 + 指令 | 匠数 deepctrl-sft-data 对话向 type；优先上采样 `history ≠ []` | Magpie-CN 约占**总盘** 8–12%（计入对话桶） |
| 知识 22% | 事实 QA | Fineweb-Edu Chinese **Pure QA** 为主 | 匠数知识 / 百科类补足 |
| 推理 15% | 短答 / 短步骤 | Congliu Chinese-DeepSeek-R1-Distill **仅 final 答案**（不用长 CoT） | 匠数数学 / 逻辑类 |
| 创作 12% | 文案 / 故事 / 改写 | 匠数生成 / 写作类 | Magpie 创作向可少量并入对话/创作 |
| 代码 8% | 短代码 | 匠数代码类（中 + 英） | 英文代码可略高于「英 20%」在代码桶内的份额，但全局语言仍控 80/20 |

### 匠数转换规则

- 字段：`instruction` / `input` / `output` / `history` → `conversations`。
- `history` 为空 `[]`：单轮（本轮 user = instruction±input，assistant = output）。
- `history` 非空：先按序展开每对 `[user, assistant]`，再追加本轮。
- 同时使用中文包与英文包，按语言总控抽样。

### 去重与质量控制

- 跨源：规范化 user+assistant 文本后 hash 去重。
- R1：只保留 final，避免超长思维链淹没小模型。
- 匠数：按 `type`（及语言、是否多轮）**分层抽样**，禁止整包灌入。

## 流水线（实现阶段；本设计不执行）

1. **下载 / 缓存**：匠数 zh+en、Fineweb Pure QA、R1-final、Magpie-CN。
2. **统一转换**为 `conversations`（含匠数 `history` 展开）。
3. **打标签**：能力桶、语言、是否多轮。
4. **分层抽样**：按锁定配比；同一 seed；先抽满 10G 超集，再从其子集得到 5G（或等价两阶段保证超集关系）。
5. **跨源去重** → **打乱** → 写 jsonl + `SOURCES_v5.md`。
6. **另一步（用户确认文件已落地后）**：删除旧 v1、改 WebUI/训练默认指向 10G、更新 `data/SFT/README.md` / Hub 卡片、上传 HF train 文件。

进行中的 `moe-sft-3` 仍指向现有 v1 路径时：**不得**在其运行中删除或替换其正在读的文件。

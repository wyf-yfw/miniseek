    Task配置

    配置阶段：「新建 Task」只打开表单、不落盘；点「创建并启动」才真正创建任务。开始后参数锁定，改配置请新建 Task。

    Pretrain：从零/续训语言模型；数据为每行 text 的 jsonl。

    MiniSeek-V：DeepSeek-V4.1-Flash 全架构（CED / CSA2 / mHC / Engram / MoE）。

    数据

    训练 jsonl。验证只从这份训练集里按比例抽，没有独立 valid 文件。Resume / Init Ckpt 由你填写。

    SFT 专属

    只对 SFT 生效。必须从预训练 .pt 微调（Init Ckpt）；若填了 Resume 则优先断点续训，Init 可空。

    DSpark 专属

    投机解码草稿头训练（主干冻结）。必须指定训练好的主干权重（PT 或 SFT 的 .pt）。

    训练超参

    Pretrain / SFT 共用，但默认值不同（SFT 通常更小 batch、更短 warmup）。Batch Mode 两种模式都可用。

    M 专属

    仅 arch=MiniSeek-V 时写入 train_* --aux-coef；D/Tiny 隐藏。SFT 默认开候选池与 Decoder Bounded Replay 模拟。

    断点 / 速度

    Resume 含优化器；与 SFT 的 Init Ckpt 不同。Compile / Fused / FlashAttention 对 PT 与 SFT 都可用。
